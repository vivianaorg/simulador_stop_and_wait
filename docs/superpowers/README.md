# Índice de specs y planes

Diseño e implementación **por feature**. Una feature = un spec + un plan, fechados.
Son documentos **de su momento**: describen lo que se decidió entonces, no el estado actual.
Para el estado de hoy, ir a [../00-INDEX.md](../00-INDEX.md).

## Convención de nombres

- Spec (diseño): `specs/AAAA-MM-DD-<slug>-design.md`
- Plan (tareas): `plans/AAAA-MM-DD-<slug>.md`

Al agregar uno, sumar la fila acá.
